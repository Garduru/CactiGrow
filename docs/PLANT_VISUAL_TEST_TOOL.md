# Plant Visual Test Tool

This is permanent **development-only** art and genetics inspection tooling. Open the Farm in the Vite development server with `/?plantTest`. Both `import.meta.env.DEV` and the query parameter are required; a production build cannot activate the tool through its URL. Closing it or loading without the query returns to ordinary gameplay.

The isolated factory in `src/dev/plantVisualTestModel.ts` creates a canonical `CollectedPlant`/`Plant` with deterministic `dev-test-plant-*` and `dev-test-clone-*` identities. It uses canonical species and genetic-feature definitions, then the same `createPlantVisualDescriptor` resolver as gameplay. It never dispatches a game action or writes owned plants, Nursery slots, Garden assignments, clone registry, inventory, progression, or persistence. The frozen preview time selects an existing two-minute growth band without changing the timer.

The Nursery target renders the real `NurserySlot` with a read-only test plant. Germinating shows the occupied pot without a cactus; Mature does not offer collection. The Garden target temporarily replaces only the front-center **render projection** in the Farm Phaser scene, retaining the real assignment in game state. Switching targets, resetting, closing, or leaving the Farm restores the live projection. Plant Details opens the real dialog with mutating controls omitted and a visual-stage preview override. The test plant cannot be sold, bred, collected, researched, listed, or awarded XP or Tokens.

Controls cover canonical species, the five Nursery presentation stages, Variegation, an explicit Pattern A/B/C test identity, six modeled morphology/spination features, and Shiny. The neutral preview is an enlarged **art-inspection surface**: it measures the visible alpha bounds of the resolved artwork, fits those bounds into a consistent viewport with padding, preserves aspect ratio, and offers Fit, 1.5×, and 2× inspection zoom. It intentionally does not preserve relative gameplay height and must not be used as evidence of Nursery, Garden, Plant Details, or Phaser world scale. The Nursery, Garden, and Plant Details targets continue to use their real production presentation rules. The debug summary shows the test IDs, species visual key, selected stage, expressed features, Shiny state, resolver support state, resolved mask, missing visual layers, and the resolved base asset or recipe. Seedling, Juvenile, Developing, and Mature Pattern A plus Mature Patterns B/C resolve registered runtime masks and report **full** support when no other unsupported visual feature is selected. Seedling B/C, Juvenile B/C, and Developing B/C retain the approved Normal body and report **partial** support. Gameplay plants do not yet persist a pattern family, so only the isolated tool supplies one; live specimens remain backward-compatible and partial until that domain decision is made. Germinating has no cactus. Future support belongs in the shared manifest/resolver/renderers, not this tool.
