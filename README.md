🌱 Welcome to CactiGrow

CactiGrow is a cactus cultivation and genetics simulation where players grow, breed, mutate, and collect unique virtual cacti.

What begins with a simple seed can evolve into an extraordinary collection.

Experiment with genetics, discover unusual mutations, develop rare varieties, and build your own cactus-growing operation.

Whether you’re chasing rare genetics, experimenting with breeding combinations, or simply expanding your collection, CactiGrow is designed to give every cactus its own identity.

This isn’t just about growing plants.

It’s about discovering what they can become.

🚧 Development Status

Currently Under Construction

CactiGrow originally began as a prototype within the CactiSwap ecosystem.

The project is now being rebuilt independently to provide greater flexibility, improved performance, and a foundation for more advanced gameplay.

The existing alpha prototype is intended to remain available during development of the new version.

The rebuild focuses on establishing a strong technical foundation before expanding into more complex game systems.

Current development areas include:

* Independent React and TypeScript application architecture.
* Authenticated player initialization.
* Backend infrastructure and database integration.
* Core cultivation and gameplay architecture.
* Plant genetics and visual variation.
* Variegation and mutation development.
* Buildings and the growing environment.
* Integration with the existing CactiSwap ecosystem.

Features will evolve throughout development.

🏗️ Built for Independence

CactiGrow is being developed as an independent application rather than remaining dependent on its original prototype platform.

This approach allows the game to evolve without being constrained by the infrastructure of the wider CactiSwap ecosystem.

The architecture emphasizes:

Modularity: Individual systems can be expanded and maintained independently.

Scalability: The foundation is designed to accommodate future gameplay additions.

Separation of Concerns: Gameplay systems remain independent of external ecosystem integrations.

Maintainability: Strong typing and a structured application architecture help keep development manageable as the project grows.

Interoperability: CactiGrow can connect with CactiSwap while maintaining control of its own core systems.

💻 Local Development

This repository contains the independently developed CactiGrow application.

Requirements

* Node.js
* npm
* Git

Clone the Repository

git clone <YOUR-REPOSITORY-URL>
cd CactiGrow

Install Dependencies

npm install

Start the Development Server

npm run dev

Build for Production

npm run build

Preview the Production Build

npm run preview

These commands cover the standard Vite frontend workflow. Backend services and database configuration may require additional setup.
